# Pseudocódigo

Pseudocódigo escrito pelo grupo antes da implementação. Os arquivos têm
extensão `.scala` apenas para facilitar a leitura/realce no editor: eles
**não ficam em `src/main/scala` e não são compilados** pelo sbt.

- `countvectorizer/`: planejamento e pseudocódigo do CountVectorizer.
- `tfidf/`: espaço para o pseudocódigo do TF-IDF.

As implementações de verdade ficam nos módulos `countvectorizer/` e `tfidf/`,
dentro de `src/main/scala`.
