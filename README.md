# Mineração de Texto - de modo escalável 

Projeto desenvolvido na disciplina de Computação Escalável do curso de **Ciência de Dados e Inteligência Artificial** da Universidade Estadual de Londrina (UEL).

Este projeto consiste na implementação de algoritmos de Mineração de Texto (TF-IDF e CountVectorizer) de modo a focar na escalabilidade.
